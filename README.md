Жұмыс туралы сипаттама:
Бұл тапсырмада объектілі-бағытталған бағдарламалаудың негізгі тұжырымдамаларын қолдана отырып, Student класын жазып шықтым:
Инкапсуляция: Студенттің аты-жөні, тобы, жасы және бағалары private секциясына жасырылған. Оларға қол жеткізу мен өзгерту үшін геттер және сеттер функцияларын жаздым.
Динамикалық жады: Бағалар тізімін сақтау үшін int* динамикалық массиві қолданылды. Элементтер саны count айнымалысында сақталады. Жаңа жады new арқылы бөлініп, деструкторда delete[] арқылы босатылады.
Deep Copy: Жады қателіктері болмас үшін көшірме конструкторда және = операторында жаңа жады бөліп, мәндерді жеке көшіретін етіп жаздым.

Const әдістер: Мәліметтерді өзгертпей, тек оқып беретін геттер функциялары const деп белгіленді.
Операторларды артық жүктеу:
operator= бір студенттің мәліметтерін екіншісіне дұрыс меншіктеу үшін қолданылады.
operator== екі студенттің аты-жөні мен тобы бірдей болса, оларды тең деп санайды.
Файлдардың құрылымы:
Student.h — Класстың және оның әдістерінің жариялануы.
Student.cpp — Класс әдістерінің іске асырылуы.
main.cpp — Программаны тексеру (объектілер құру, көшіру, салыстыру).
